### **ОБЩИЕ СВЕДЕНИЯ И ГЛОССАРИЙ**

- **Конкурс** — общая сущность интерактивного элемента на платформе (может быть Квизом или Голосованием).
- **Квиз (Викторина)** — опрос, в котором у каждого вопроса есть как минимум один правильный ответ. За правильные ответы пользователю начисляются баллы.
- **Голосование** — опрос с целью выявления мнения, где понятия «правильный ответ» не существует.
- **Организатор** — авторизованный пользователь, создавший Конкурс.
- **Участник** — пользователь (авторизованный или гость), проходящий Конкурс.
- **Блок комментариев** — интерактивная лента под Конкурсом для обсуждения.



### **АРХИТЕКТУРА И СТЕК ТЕХНОЛОГИЙ**

- **Backend:** PHP 8.x+, Laravel.
- **Frontend Routing & State Transfer:** Inertia.js.
- **Frontend:** React 18+.
- **UI Library:** Ant Design (Antd) v5+.
- **Database:** PostgreSQL.
- **Кеш и очереди:** Redis.



### **РОЛЕВАЯ МОДЕЛЬ (USER ROLES)**

- **Пользователь (Авторизованный):**   
	- Участие в любых открытых Конкурсах (с ограничением «1 участник = 1 отправка»).
    - Добавление комментариев, ответы на чужие комментарии.
    - Личный кабинет (просмотр истории своих участий и набранных баллов в конкурсах).

- **Организатор:**
    - Доступ к Конструктору конкурсов (создание, редактирование, удаление своих черновиков).
    - Управление статусом своего Конкурса (Публикация, Приостановка, Завершение).
    - Просмотр детальной аналитики и статистики по своим Конкурсам.

- **Администратор:**
    - Полный доступ к панели управления.
    - Модерация любого контента (удаление/редактирование конкурсов и комментариев).



### **ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ И ИНТЕРФЕЙСЫ (ПРИВЯЗКА К ANT DESIGN)**

#### Модуль "Конструктор конкурсов" (Интерфейс Организатора, Администратора)

- Экран списка: Таблица всех созданных конкурсов с пагинацией и фильтрами по статусу.
    - Компоненты Antd: Table, Tag (для статусов: зеленый — active, желтый - paused, серый — draft, красный — closed), Button.
- Экран создания/редактирования: Форма с названием, типом конкурса, описанием, периодом проведения
    - при создании:
        - добавить кнопку "Сохранить как черновик"
        - добавить кнопку "Опубликовать"
    - при редактировании:
        - изменение статуса делать через быстрые экшены (dropdown) вверху страницы (возможность выбора статуса: paused, active, closed)
        - остальные поля редактируются и кнопка "Сохранить"
    - Поля:
        - Название (`Input`)
        - Тип конкурса (`Select`)
        - Описание (`Input.TextArea`)
        - Период проведения (`DatePicker.RangePicker`)
        - Динамические поля (текствое поле `Input`, поле ввода текста `Input.TextArea`, список `Select`)


#### Модуль "Конструктор голосований"

- Экран создания/редактирования:
    - Поля:
        - Название (`Input`)
        - Описание (`Input.TextArea`)            
        - Ввод данных в динамические поля, которые были созданы в настройках конкурса (`Array<Input | Input.TexArea | Select>`)
        - Загрузка файлов (возможность указать главный файл, например, если это изображение, то отображать его на карточке) (`Array<Upload, Radio>`)
        


#### Модуль "Конструктор квиза"

- Поля:
    - Название (`Input`)
    - Описание (`Input.TextArea`)
    - Список вопросов, отметка правильного ответа (`Array<Input, Checkbox>`)
    - Ввод данных в динамические поля, которые были созданы в настройках конкурса (`Array<Input | Input.TexArea | Select>`)
    - Загрузка файлов (возможность указать главный файл, например, если это изображение, то отображать его на карточке) (`Array<Upload, Radio>`)
    - Период отображения (с учетом времени)
